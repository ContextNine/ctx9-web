# Tenant and account settings mocks

Matt selected the Impression-style direction in the implementation request: a centered, near-full-viewport dialog with a left tab rail and the same opacity and scale motion. Mock A records that selected direction. Mocks B and C preserve the two rejected layout alternatives required by the shared UI design process.

- `a-impression-scale.html`: selected, 90vw by 92vh with a wide left rail.
- `b-compact-dialog.html`: rejected, compact centered dialog.
- `c-narrow-rail.html`: rejected, narrower rail and denser content.

These mocks contain no runtime code or data and are not shipped in `@ctx9/ui`.
