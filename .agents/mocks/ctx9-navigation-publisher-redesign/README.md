# CTX9 navigation and Publisher redesign mocks

These static mocks cover the approval gate for the shared breadcrumb work and Publisher redesign. They use synthetic data and do not connect to CTX9 services.

- `a-inline-row.html` expands the selected publication beneath its table row.
- `b-side-sheet.html` keeps the inventory visible while a right-side editor opens.
- `c-focused-dialog.html` uses a compact dialog for metadata editing.

Every direction includes Publisher inventory and detail, a nested Secrets route, Testimonials form and response routes, the shared account menu, narrow-screen behavior, and the canonical CTX9 favicon.
