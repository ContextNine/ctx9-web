# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ContextNine/ctx9-web/security/advisories/new). Do not include credentials, protected configuration, session material or customer data in a public issue.

Include the affected package/version, a minimal reproduction using synthetic values, and the expected security boundary. Ordinary bugs and contribution questions can use public issues.

Security fixes target the current public release line. Consumers should pin an exact supported version and follow the release notes when upgrading.
